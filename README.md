# DimPage — 钉子的个人主页们

这里存着我从 2013 年至今的个人主页：13 份实体快照，分成两条谱系。

线上最新版：<https://im.dimpurrc.com>

## 两条谱系

这些主页对应两个身份，各自慢慢发展：

| | `dp-` dimpurr | `dc-` dimchen |
|---|---|---|
| 身份 | 私人 · 网络 · 技术宅圈 | 现实 · 工作 · 专业 |
| 语言 | 中文为主（2026 版转英文） | 英文 |
| 内容 | 我是谁、在玩什么、链接到哪 | 我做过什么、简历、作品集 |
| 起点 | 2013 | 2023 |

分岔点是 `dp-univer-2022/`。它是在 `dp-univer/` 上打的补丁，内容是把现实身份（RCA / BUPT）写进来，再加一个通往 dimchen.com 的国际版入口。两份文件差别很小：`script.js` 逐字节相同，`index.html` 大约有二十处不同。因为这点差异是两条谱系分开的地方，所以两份都保留了。

## 说明

- 年代按内容判断，不看文件时间。目录 mtime 都被批量 touch 过；依据是页内自述（初三/高一/大一）、slogan 日期、旧年表记录。
- `dp-modern` 系那四份是同一套代码在不同时期的切片，不是四个不同设计。`-final` 是当年确实以为做完了才起的名，三年后又改了一版，名字就没动。
- 早期页面引用的 `res.dimpurr.com` / `res.cheny.org` 等主机已随域名丢失下线（`dimpurr.com` 2013 年起持有，后因续费失败被拍卖），图片和 jQuery 会 404。素材已就地放进 `res/`，但旧页面的绝对链接没有改写，保持原样是刻意的。
- `dp-ornate/` 原本在站点根目录，页内相对链接在仓库内失效（且它链的 `dp-dimchen` 在这里叫 `dp-univer-2022`），去线上看。
- `dp-dimlens17/` 从未部署过。
- `dp-ornate-colle/` 的数据放在 `data/*.js` 里，是 JSON 字面量套了个 `window.X =`。用 `.js` 不用 `.json`，
  是因为 `fetch()` 在 `file://` 下会被 CORS 拦，而这个仓库大多数时候是从磁盘直接打开的。
- 2013 年之前没有存档。
